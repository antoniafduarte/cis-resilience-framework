# Spreadsheet style guide

| Element | Colour | Hex |
|---|---|---|
| Primary titles and headers | Dark blue | `#17365D` |
| Inputs, provenance and attention fields | Yellow | `#FFD966` |
| Calculation and reference areas | Grey | `#D9D9D9` |
| Output and reading areas | White | `#FFFFFF` |

Use the same colour meaning in all subsystem, integrated and analytical workbooks. Do not introduce additional colours unless needed for a clearly documented warning or validation status.
