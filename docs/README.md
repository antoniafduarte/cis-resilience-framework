# Documentation

This directory is reserved for user-facing documentation supporting the CIS Resilience Framework.

## Planned contents

- `User_Guide.pdf` — step-by-step instructions for preparing inputs, running the workbooks and interpreting outputs
- `Methodology.pdf` — indicator definitions, normalisation, weighting and aggregation procedures
- `Framework_overview.png` — visual summary of the six-subsystem architecture and integrated assessment workflow

Documentation should use the same workbook names, indicator terminology and version numbers as the public tools. Superseded files should be removed or clearly marked as archived.
