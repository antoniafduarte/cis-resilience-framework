# Examples

This directory is reserved for reproducible examples showing how to use the CIS Resilience Framework without exposing confidential operational data.

## Structure

- `Example_inputs/` — anonymised or synthetic datasets formatted for the public workbooks
- `Example_outputs/` — corresponding indicator tables, subsystem results and dashboard examples

Each example should identify:

- the workbook and version used;
- the assessment period;
- whether data are synthetic, anonymised or public;
- local thresholds and parameter assumptions;
- any omitted indicators;
- the expected main outputs.

Examples are illustrative and should not be treated as universal benchmarks or recommended threshold values.
