# Paper materials

This directory is reserved for materials associated with the scientific publication describing and applying the CIS Resilience Framework.

## Structure

- `Figures/` — publication figures or repository-ready versions
- `Supplementary_material/` — supplementary tables, methods, validation material and supporting files

Only material authorised for public dissemination should be included. Manuscript drafts containing tracked changes, reviewer comments, personal information or unpublished confidential data should not be uploaded.

The final article citation and DOI will be added to the repository when available.
