# Integrated CIS Resilience Framework

This folder contains the autonomous Excel workbook used to integrate the results of the six subsystem assessments into a common resilience profile.

## Current public version

`CIS_integrated_resilience_framework_tool_v3_public.xlsx`

Version 3 is the current public release of the integrated framework and supersedes earlier draft versions. Users should apply this workbook for new assessments and cite the exact file name and version used.

## Purpose

The integrated tool consolidates the results from Subsystems A–F while retaining the diagnostic information provided by individual indicators, operational dimensions and subsystem scores.

## Version 3 features

- Integration of the six subsystem assessments (A–F)
- Indicator-, dimension- and subsystem-level aggregation
- Overall CIS resilience score
- Comparative dashboards and resilience profiles
- Internal completeness, consistency and validation checks
- Support for documented indicator omissions and local adaptations
- Recording of data sources and confidence information

## Required inputs

- Normalised indicator results or subsystem-tool outputs
- Indicator and dimension weights
- Assessment period and case-study identification
- Data-source and confidence information
- Documented omissions or local adaptations

## Main outputs

- Indicator-level results
- Operational-dimension scores
- Six subsystem scores
- Overall CIS resilience score
- Comparative dashboards and resilience profiles
- Completeness, consistency and validation checks

## Recommended workflow

1. Complete and validate each applicable subsystem workbook.
2. Transfer the required results to the integrated workbook.
3. Confirm indicator availability and weighting.
4. Review validation checks and warnings.
5. Interpret the integrated score together with the subsystem and indicator profiles.

## Interpretation

The overall score is a synthesis, not a substitute for diagnosis. Similar integrated scores can reflect different weaknesses; therefore, bottlenecks should be identified from the subsystem, dimension and indicator results.

When one or more complete subsystems are unavailable, report the result as a partial resilience profile and avoid direct comparison with complete six-subsystem assessments.

## Software requirements

A recent desktop version of Microsoft Excel is recommended. No external software or programming environment is required.
