# Subsystem C — Conveyance and Distribution

This folder contains the Excel tool for assessing conveyance- and distribution-network resilience.

## Main workbook

`RI_SC_conveyance_distribution_tool_v1_1_public.xlsx`

## Assessment focus

Subsystem C evaluates hydraulic and service performance from conveyance through distribution, with emphasis on the reliability and severity of delivery failures.

## Typical inputs

- Conveyed, distributed and delivered volumes
- Conveyance and distribution losses
- Hydrant operating records
- Required and observed pressure
- Failure duration and severity
- Network capacity and service standards

## Main outputs

- Conveyance and distribution efficiency indicators
- Hydrant pressure reliability
- Relative pressure-deficit severity
- Service-failure indicators
- Normalised indicator and dimension scores
- Subsystem C resilience score and dashboard

## Workflow

1. Define local delivery standards and pressure requirements.
2. Enter annual or operational network data.
3. Verify loss calculations and failure classification.
4. Review indicators, validation checks and missing-data warnings.
5. Use the dashboard to identify hydraulic and service bottlenecks.

## Notes

Pressure-based indicators depend on common failure records and may be strongly associated. Results should be interpreted as complementary measures of reliability and severity rather than as independent processes.
