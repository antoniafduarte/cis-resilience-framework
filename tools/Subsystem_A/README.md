# Subsystem A — Water Availability

This folder contains the Excel tool for assessing water-availability resilience in a pressurised collective irrigation system.

## Main workbook

`RI_SA_water_availability_tool_v1_1_public.xlsx`

## Assessment focus

Subsystem A evaluates the reliability and persistence of water availability using indicators related to inflow conditions, drought duration, storage context and dependence on carry-over storage.

## Typical inputs

- Monthly or seasonal inflow series
- Drought thresholds and classification rules
- Reservoir storage and usable capacity
- Irrigation demand or allocation context
- Assessment period and data-source information

## Main outputs

- Time-based inflow reliability
- Volume-based inflow reliability
- Mean drought duration
- Storage-context indicators
- Carry-over dependence
- Normalised indicator and dimension scores
- Subsystem A resilience score and dashboard

## Workflow

1. Define the assessment period and local thresholds.
2. Enter and verify inflow and storage data.
3. Review drought classification and indicator calculations.
4. Check data completeness and validation messages.
5. Interpret the final score together with the individual indicators.

## Notes

Thresholds and usable-storage assumptions must be adapted to the local system and documented in the source register. Identical scores should not be assumed to represent identical hydrological conditions when thresholds differ.
