# Subsystem F — Drought Management Capacity

This folder contains the Excel tool for assessing drought-management capacity.

## Main workbook

`RI_SF_drought_management_tool_v1_1_public.xlsx`

## Assessment focus

Subsystem F evaluates the institutional and operational capacity to anticipate, monitor, respond to and learn from drought conditions affecting collective irrigation service.

## Typical inputs

- Drought plans and operating procedures
- Monitoring and early-warning practices
- Allocation and restriction rules
- Communication and stakeholder-coordination evidence
- Emergency and recovery measures
- Assessment responses, sources and confidence levels

## Main outputs

- Preparedness and planning indicators
- Monitoring and early-warning indicators
- Response and coordination indicators
- Learning and adaptive-management indicators
- Normalised indicator and dimension scores
- Subsystem F resilience score and dashboard

## Workflow

1. Define the assessment team and evidence base.
2. Complete the management assessment using documented information.
3. Record the source and confidence level of each response.
4. Review completeness and consistency checks.
5. Discuss low-scoring items with managers and stakeholders.

## Notes

This subsystem assesses demonstrated capacity rather than the mere existence of documents. Scores should be supported by traceable evidence and interpreted in the local legal, institutional and organisational context.
