# Subsystem B — Reservoir Service

This folder contains the Excel tool for assessing reservoir-service resilience.

## Main workbook

`RI_SB_reservoir_service_tool_v1_public.xlsx`

## Assessment focus

Subsystem B evaluates the ability of reservoir storage and operating conditions to support irrigation service over the assessment period.

## Typical inputs

- Reservoir storage and capacity data
- Inflows and releases
- Irrigation demand or supplied volumes
- Minimum operating levels
- Initial-storage assumptions
- Assessment period and source information

## Main outputs

- Service-reliability indicators
- Supply-deficit indicators
- Storage and operating-performance indicators
- Normalised indicator and dimension scores
- Subsystem B resilience score and dashboard

## Workflow

1. Define reservoir capacity, usable storage and operating constraints.
2. Enter the time series required by the workbook.
3. Confirm initial conditions and demand assumptions.
4. Review the calculated indicators and validation checks.
5. Interpret the final score together with annual variability and critical periods.

## Notes

Results may be sensitive to initial storage, minimum operating level and demand assumptions. These parameters should be documented and tested when the tool is used for scenario analysis.
