# Contributing

Thank you for your interest in the CIS Resilience Framework.

## Reporting problems

Use the GitHub issue tracker to report calculation errors, broken formulas, unclear instructions, compatibility problems or documentation gaps. Include:

- workbook and version;
- worksheet and cell reference, when applicable;
- a clear description of the problem;
- steps required to reproduce it;
- expected and observed behaviour;
- screenshots or a minimal anonymised example, when useful.

Do not upload confidential operational data, personal information or restricted datasets.

## Proposing improvements

Suggestions for new indicators, thresholds, validation checks, dashboards or documentation are welcome. Proposals should explain:

- the problem addressed;
- the scientific or operational justification;
- required data;
- expected effect on comparability and interpretation;
- relevant references.

## Pull requests

Keep changes focused and document them clearly. For workbook modifications, identify all changed worksheets, formulas, named ranges, validations and charts. Confirm that external links have been removed and that no confidential data are included.

## Scientific integrity

Contributions must preserve traceability, transparent assumptions and reproducible calculations. Local thresholds or parameter values should not be presented as universally applicable.
